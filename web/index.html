Real-time Exness feed (MT5 bridge)

Exness has no public price API — its real-time market data lives in your MT5 terminal. Run the bridge on the PC that has your Exness MT5 logged in, and it will stream live prices into this app (works behind this preview URL).

  1. On your Windows PC: pip install MetaTrader5 requests
  2. Download mt5_bridge.py
  3. Run: python mt5_bridge.py --url <this-app-url> --token <token>
